# Requerimentos dos Professores

Interface de requerimentos da Companhia dos Professores para uso no fórum da Polícia RCC.

## Arquivos

- `index.html`: estrutura e aparência da página.
- `script.js`: lógica dos formulários, BBCode, postagens, mensagens privadas e integrações.
- `app.gs`: coletor assíncrono para Google Apps Script.

O `index.html` carrega a lógica publicada pelo GitHub Pages em:

`https://rimixyz.github.io/prof-requerimentos/script.js`

As alterações entram no site depois de serem enviadas para a branch `main` e publicadas pelo GitHub Pages.
